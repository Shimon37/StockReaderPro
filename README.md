# StockReaderPro

אפליקציית דסקטופ (Electron + React + TypeScript) שמטרתה לקצר את זמן הניתוח הראשוני של גרף
מניה — במיוחד penny stocks — משעה לכמה דקות. הכלי לא אומר לך מה לעשות; הוא מבצע אוטומטית את
העבודה החוזרת (זיהוי רמות תמיכה/התנגדות, בדיקת פריצות, נפח מסחר, מומנטום) ומציג ציון ותקציר
שקוף, כדי שתוכל להחליט בעצמך מהר יותר האם שווה להעמיק.

## מה יש כאן

- **סורק Watchlist** — מריץ ניתוח על כל הטיקרים שבמעקב ומדרג אותם לפי ציון.
- **ניתוח טכני אוטומטי** — רמות תמיכה/התנגדות (מבוסס pivots), זיהוי breakout/breakdown,
  נפח יחסי מול ממוצע 20 יום, RSI, ATR, ותנודתיות.
- **ציון "שווה בדיקה" (0-100)** — ציון מורכב עם פירוט מלא של כל גורם שהשפיע עליו (שקוף,
  לא קופסה שחורה).
- **תקציר טקסטואלי** לכל טיקר, נגזר מהנתונים בפועל.
- **גרף נרות + נפח** עם קווי תמיכה/התנגדות מצוירים עליו (lightweight-charts).

## מקורות נתונים

- **Stooq** (ברירת מחדל, ללא צורך במפתח API) — היסטוריית מחירים יומית (OHLCV) חינמית.
  זו הסיבה שהאפליקציה עובדת "מהקופסה" בלי שום הרשמה.
- **Finnhub** (אופציונלי) — אם תוסיף מפתח API חינמי משלך בעמוד ההגדרות, האפליקציה תשלוף גם
  מחיר עדכני (quote) מעבר לנתוני הסגירה היומיים. אפשר לקבל מפתח חינמי בכתובת
  https://finnhub.io/register.

> כיסוי נתונים למניות OTC/penny stock דלות מסחר לא מובטח במקורות חינמיים. אם טיקר לא נמצא,
> האפליקציה תציג הודעה מפורשת במקום שגיאה סתומה.

## מבנה הקוד (Separation of Concerns)

```
src/
  shared/types.ts          טיפוסים משותפים בין main ל-renderer
  main/
    marketData/             שכבת נתונים בלבד — שליפה חיצונית + קאש מקומי
    analysis/               מנוע ניתוח טהור (ללא I/O, קל לבדיקה): אינדיקטורים,
                            רמות, זיהוי breakout, ציון, תקציר
    config.ts               קריאה/כתיבה של הגדרות משתמש (מפתח API, watchlist)
    ipc.ts                  חוט חיבור בין הלוגיקה ל-renderer (IPC בלבד, אין לוגיקה)
  preload/                  גישור מאובטח (contextBridge) בין main ל-renderer
  renderer/src/
    components/             תצוגה בלבד — קוראות ל-window.api, לא נוגעות בלוגיקת ניתוח
```

הרעיון: אפשר להחליף ספק נתונים (`marketData/`), לשנות את נוסחת הציון (`analysis/score.ts`)
או להוסיף תקציר מבוסס-LLM במקום התבנית הנוכחית (`analysis/summary.ts`) — בלי לגעת בשאר
השכבות.

## הבהרה חשובה

הציון והתקציר האוטומטיים הם ניתוח טכני גרידא ואינם המלצת קנייה/מכירה ואינם ייעוץ השקעות.
הכלי נועד לזרז את שלב הסינון הראשוני בלבד — ההחלטה, בדיקת הנזילות, גודל הפוזיציה וניהול
הסיכון נשארים באחריותך, בפרט במניות penny stock שבהן התנודתיות והפערים (spreads) גבוהים.
